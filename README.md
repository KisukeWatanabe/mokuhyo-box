# 目標BOX

マンダラチャート(9×9=81マス)で長期目標を可視化し、週次リストと双方向連携させる iOS 向けアプリ。
React Native + Expo + TypeScript / Zustand / AsyncStorage(ローカルファースト)。

## 起動方法

```bash
npm install
npx expo start   # Expo Go アプリ(iPhone)で QR を読み取る
```

## 画面構成

| タブ | 画面 |
| --- | --- |
| マンダラ | 目標マップ(3×3・中目標)⇄ 全体マップ(9×9・81マス、画面幅に自動フィット) |
| マンダラ → マス | 中目標詳細(小目標3×3)。タップで「今週にとり込む」シート |
| 今週 | 週次リスト(○×型 / 回数型 / 数値型 / 動的チェックリスト型)+ フリー項目追加 |
| 振り返り | これまでの記録(年 → 月 → 週 でたどって過去の週次リストを確認・編集) |

## 操作方法

- **マスをタップ**: 中目標→詳細へ / 小目標→今週にとり込む
- **マスを長押し**: 書き換え・頻度変更・削除・位置の入れ替え
- **空きマス(＋)をタップ**: 新規追加
- **週次カードを長押し**: 削除(マンダラ側は「未着手」に戻る)
- 週次リストで目標を達成すると、マンダラのマスが緑に変わる(双方向同期)

## 未決定事項への仮決定(CLAUDE.md 8章)

1. **継続習慣の達成判定**: 週次リスト側の実績で判定。週の目標(回数/日数)を
   満たすとその週はマスが「達成済み(緑)」。翌週の自動再取り込みで
   「週次リストに追加済み」に戻る(習慣は毎週リセット)。
   ○×型×毎日は「週5日以上」で達成扱い。→ `src/store/useAppStore.ts`
2. **PencilKit 手書き入力**: 未対応(テキスト入力のみ)。フォントは
   手書き風(Yomogi)+ 丸ゴシック(Zen Maru Gothic)で紙の質感を再現。
3. **保存先**: AsyncStorage による端末ローカルのみ。クラウド同期は持たない
   (アプリ削除・機種変更でデータは失われる旨を設定画面で告知)。

## 通知

オン/オフの入口は2つ。

1. **オンボーディング Step 6**(`app/onboarding.tsx`)— 自分で目標を1つ作り、
   週次リストに並んだ直後に「通知を受け取る / あとで」で聞く。
   設定画面に置くだけでは開かれないため、値打ちが伝わるこの位置で許可を取る
2. **設定タブ →「通知の設定」**(`app/notifications.tsx`)— 後から変更する場所。
   通知を増やすときはこのページにカードを足す

**今週の目標リマインド**(月曜6:00 / 催促18:00 の固定。曜日・時刻は選ばせない)

| いつ | 内容 |
| --- | --- |
| 毎週 月曜 6:00 | 「今週の目標は何ですか?」(常に届く) |
| 月・火・水 18:00 | 「今週の目標がまだ空です」(その週の目標が0件のときだけ) |

**1週間に届く通知は最大4回**(月6:00 + 月火水18:00)。木曜以降は催促しない。
週の後半に言い続けても意味が薄れるうえ、鳴らしすぎると通知自体を切られるため。

通知は OS へ前もって予約する仕組みで、鳴る瞬間に条件を判定できない。
そのため**催促を先に仕込んでおき、目標が入ったら取り消す**という作りにしている。
週次リストはアプリを開かないと変化しないので、開いたときに貼り直すだけで整合する。

- 催促は識別子 `weekly-goal-nudge-<日付>` で1日1件。**2週間先まで**仕込む
  (週をまたいでもアプリを開かない人に届けるため)
- 目標が1件でも入っている週は、その週の催促をまるごと飛ばす
- 端末内で完結する**ローカル通知**のみ。端末トークンを外部へ送るプッシュ通知は使わない
  (プライバシーポリシーの「外部送信なし」を保つため)
- OS への予約は `useGoalReminderSync`(`app/_layout.tsx`)が一手に引き受ける。
  画面側はストアを書き換えるだけ。起動のたびに貼り直すので端末再起動でも消えない
- 通知タップで「今週」タブへ遷移する
- 「通知を試してみる」で3秒後にテスト送信できる

> Expo Go では通知の挙動が実機ビルドと異なる場合がある。確認は development build 推奨。

## アイコン / スプラッシュ

原画は `assets/images/mokuhyo-box-icon.png`(2048px)の1枚だけ。
そこから用途別の素材を書き出す。

```bash
npm run build:icons
```

| 出力 | 用途 |
| --- | --- |
| `icon.png` | アプリアイコン(不透明・角丸なし。iOS が独自にマスクするため) |
| `splash-icon.png` | スプラッシュのマーク(グリッドのみ・背景透過) |
| `android-icon-foreground.png` | Android アダプティブアイコンの前景(安全領域62%) |
| `favicon.png` | web |

起動時は OS のスプラッシュ → `SplashOverlay` へクロスフェードで引き継ぐ。
同じマークを同じ大きさで描いているため継ぎ目が見えない。
オーバーレイは空きマスが順に緑へ埋まるアニメーションを見せたあと、
保存データの復元完了を待って溶暗する(復元前の空の画面がちらつかない)。
尺は約4.8秒(埋まる2.6s → 静止1.0s → 溶暗1.1s)。
タップすれば0.16秒で閉じる。「視差効果を減らす」設定時はアニメーションを省略する。
尺の調整は `SplashOverlay.tsx` 冒頭の定数だけで完結する。

原画を描き直したら `npm run build:icons` を再実行し、
`src/components/SplashOverlay.tsx` の寸法・色の定数も見直すこと。
